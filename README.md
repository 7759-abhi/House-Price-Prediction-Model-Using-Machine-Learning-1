# House Price Prediction Model

ML project comparing Linear Regression and Random Forest for residential
price prediction, with an interactive Streamlit app.

## Project structure
```
house_price_project/
├── app.py                  # Streamlit app (run this)
├── requirements.txt
├── data/
│   └── house_data.csv      # 1,200-record synthetic dataset
├── src/
│   ├── generate_data.py    # synthetic data generator
│   ├── preprocessing.py    # shared preprocessing pipeline (train + inference)
│   └── train_models.py     # trains & evaluates both models, saves artifacts
└── models/                 # saved models, scaler, metrics (generated by train_models.py)
```

## How to run

```bash
pip install -r requirements.txt

# (Optional) regenerate data and retrain from scratch:
python src/generate_data.py
python src/train_models.py

# Launch the app:
streamlit run app.py
```

## Methodology
- **Dataset**: 1,200 synthetic residential records across 8 Indian cities,
  14 raw features (structural + categorical), with realistic injected
  correlations (Area, Distance-to-Center, City, Property Type, etc. all
  drive Price).
- **Preprocessing**: mean/median imputation for missing values (~3% across
  3 fields), IQR-based outlier capping on Price/Area/Lot Size, one-hot
  encoding for nominal fields, ordinal encoding for Property Condition.
- **Feature engineering**: 6 engineered features — Property Age,
  Bath-to-Bed Ratio, Lot per Bedroom, Total Living Units Score, Location
  Quality Index, Area per Room.
- **Models**: Linear Regression (OLS baseline) and Random Forest
  (`n_estimators=100, max_depth=15, min_samples_split=5,
  min_samples_leaf=2`).
- **Split**: 80/20 train-test, `random_state=42`, plus 5-fold CV.

## Known deviation from the original report
The report's "Price per Square Foot" engineered feature (`Price / Area`)
leaks the target variable into the inputs. This implementation replaces it
with **Area per Room** instead, which keeps the same spaciousness signal
without leaking Price — so the R² scores here are genuine, not inflated.
